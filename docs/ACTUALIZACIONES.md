# Actualizaciones Android desde Mesa

Mesa 1.5.0+9 incorpora **Mi espacio → Actualizar Mesa**. La instalación inicial de esta versión se hace una vez desde el enlace privado, sobre la anterior y sin desinstalar. A partir de ahí la app busca versiones, muestra novedades, descarga con progreso, permite cancelar/reintentar y abre el instalador de Android tras verificar el APK. Los datos locales, borradores y conexión familiar permanecen en el mismo paquete `com.mesa.mesa`.

El canal es HTTPS privado por Tailscale, independiente de las credenciales del servidor familiar. Requiere Tailscale activo y el ordenador distribuidor encendido. El servicio de descargas solo expone el manifiesto y los APK de `dist`, sin navegación de carpetas ni datos familiares. Se inicia oculto con `Iniciar-Mesa.cmd`. La ruta `/descargar` se añade a Tailscale Serve en el puerto 9443, conservando las rutas ya configuradas. Se mantiene también el enlace de descarga previo.

El manifiesto indica versión, código, tamaño, SHA-256, Android mínimo, arquitecturas, novedades y una ruta de APK inmutable. El cliente rechaza redirecciones ajenas, respuestas grandes, metadatos incorrectos y versiones incompatibles; una consulta fallida ofrece reintentar. La descarga nativa valida TLS, tamaño y SHA-256, limita bytes/plazos y elimina archivos parciales. Antes de instalar se vuelve a comprobar el archivo, su paquete, código superior y firma idéntica a la instalada. La versión actual exige conservar la misma clave, sin rotación de firmantes. El instalador recibe una URI de FileProvider limitada a `cache/updates`, con permiso temporal de lectura.

Android exige autorizar el origen de instalación cuando corresponde. Se abre el permiso de Mesa; al volver con permiso se abre el instalador, y al volver sin permiso se informa sin reabrir los ajustes en bucle. La instalación requiere confirmación del usuario. Cancelar el instalador permite intentarlo otra vez. Consultar o descargar no instala nada automáticamente. Referencias primarias: [PackageManager.canRequestPackageInstalls](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls()), [FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider), [SigningInfo](https://developer.android.com/reference/android/content/pm/SigningInfo) y [Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve).

Publicación: incrementa `client/pubspec.yaml`, actualiza `client/update_notes.json` y ejecuta `scripts/build.ps1 -Target android`. El script firma con la clave existente y verifica los componentes nativos; el publicador contrasta versión/paquete con el APK, conserva un nombre versionado y reemplaza atómicamente el manifiesto. Rechaza reutilizar versión/código para otros bytes. Conserva los APK anteriores para que una publicación nueva no interrumpa una descarga iniciada. El cliente puede cambiar de distribuidor compilando con `--dart-define=MESA_UPDATE_FEED=https://nuevo-equipo/.../update.json`.

Validación de 1.5.0+9: análisis limpio, 58 pruebas Flutter y 48 Python, compilaciones Windows y Android ARM64 correctas. Pruebas del actualizador: metadatos, origen/redirecciones, límites, versión/compatibilidad, errores, progreso, cancelación, reintento y retorno de permisos concedidos/denegados. El fallo de firma en la interfaz se prueba con una respuesta nativa simulada; no constituye una prueba del PackageManager de un teléfono real. El servicio se prueba con GET/HEAD reales y rechazo de rutas ajenas; la publicación comprueba inmutabilidad y avance del manifiesto.

Verificación de entrega: `scripts/verify_update_release.py` descarga el APK completo por HTTPS privado, comprueba hash y tamaño contra el manifiesto/local, verifica la firma pública coincidente y examina permiso, proveedor y ruta compilados. APK: 52.245.975 bytes, SHA-256 `4b03167f24ccbb40d40df174a1fe2fdffee261e6141f9bbf1cedac74094077d6`. No había teléfono conectado por ADB: quedan por verificar físicamente el permiso, la instalación y la conservación de datos después de actualizar.

Mesa 1.6.1+11 retira los tres catálogos documentales y convierte las fotos en referencias en línea. Se publica con la misma firma, por lo que la versión 1.5.0 o cualquier posterior puede encontrarla en Actualizar Mesa. Ver fotos necesita Internet; guardar y sincronizar transmite solo enlaces y créditos.
